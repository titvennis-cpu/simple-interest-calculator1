# Simple Interest Calculator

This repository contains a simple interest calculator project.

## Description

The Simple Interest Calculator is a basic program that calculates simple interest based on the principal amount, annual rate of interest, and time period in years.

## Formula

Simple Interest = (Principal × Rate × Time) / 100

Where:

- Principal is the initial amount of money
- Rate is the annual interest rate
- Time is the time period in years

## Example

If the principal amount is 1000, the rate is 5%, and the time is 2 years:

Simple Interest = (1000 × 5 × 2) / 100 = 100
